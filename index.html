Project documentation

README

Personal portfolio website built with HTML and CSS.

Features

  • Modern dark theme with a responsive layout.
  • Navigation links to About, Projects, Skills, Contact, and README.
  • Hero section with clear calls to action.
  • Project cards and skill badges.
  • Clickable email and social links.
  • Keyboard focus states, semantic sections, and reduced-motion support.

Built With

  • HTML5 for structure and semantic content.
  • CSS3 for layout, responsive styling, and visual design.
  • Font Awesome for icons.

How to Customize

  1. Place your profile image in the same folder and name it profile.jpg.
  2. Replace the sample project descriptions with your actual projects, GitHub repositories, and live demos.
  3. Replace YOUR_GITHUB_USERNAME in the GitHub link with your username.
  4. Add any additional skills, a LinkedIn profile, or a résumé link you want to share.

Before publishing: check every link and replace the sample project content and GitHub placeholder with your real details.
